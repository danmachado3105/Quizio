# ✦ Quizio

### Conhecimento vira jogo.

O **Quizio** é uma plataforma interativa de quizzes criada para transformar conhecimento em diversão. Explore diferentes categorias, teste suas habilidades, supere desafios e evolua a cada partida.

Mais do que responder perguntas, a ideia é criar uma experiência envolvente, com uma identidade visual marcante, animações e mecânicas de progressão que incentivam você a continuar jogando.

---

## ✨ O projeto

O Quizio combina uma interface moderna com elementos de gamificação para tornar cada partida mais divertida e desafiadora.

- 🧠 **Diversas categorias** — explore diferentes assuntos e descubra novos conhecimentos.
- 🎮 **Modos de jogo** — diferentes formas de testar suas habilidades.
- ⚡ **Desafios e pontuação** — responda, acumule pontos e tente superar seus recordes.
- 🏆 **Conquistas e progressão** — evolua, ganhe XP e acompanhe seu desempenho.
- 📊 **Estatísticas pessoais** — visualize seu histórico e acompanhe sua evolução.
- 🎨 **Experiência visual** — interface pensada para unir personalidade, clareza e interatividade.
- 📱 **Design responsivo** — experiência adaptada para diferentes tamanhos de tela.
- 💾 **Persistência local** — salve seu progresso no navegador.

> *Aprender, descobrir e jogar. Tudo em um só lugar.*

---

## 🛠️ Tecnologias

O projeto utiliza tecnologias fundamentais da web, sem depender de frameworks de interface.

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura e organização das páginas |
| CSS3 | Identidade visual, layouts, responsividade e animações |
| JavaScript | Lógica dos quizzes, interações e funcionalidades |
| LocalStorage | Persistência de progresso e preferências no navegador |

---

## 🎯 Objetivo

O Quizio nasceu da vontade de criar um produto digital que fosse além de um quiz tradicional. A proposta é combinar entretenimento, aprendizado e uma experiência visual agradável em uma plataforma acessível e fácil de usar.

O projeto também é uma oportunidade de colocar em prática conhecimentos de desenvolvimento web, organização de código, lógica de programação, design de interfaces e experiência do usuário.

---

## 🚀 Como executar

Como o projeto utiliza HTML, CSS e JavaScript puro, você pode executá-lo localmente sem instalar dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/danmachado3105/Quizio
   ```

2. Entre na pasta do projeto:

   ```bash
   cd quizio
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code.
